# Agent Permission Boundaries — an Agent Skill by The Ask Why Company

Define actions an AI agent may complete independently and actions reserved for explicit human approval, including money, security settings, production, publication, and irreversible changes.

Read the skill: [skills/agent-permission-boundaries/SKILL.md](skills/agent-permission-boundaries/SKILL.md)

Works with any agent that reads the open Agent Skills `SKILL.md` format.

## Use it with any AI agent

Install with a compatible skills installer:

```sh
npx skills add theaskwhy/agent-permission-boundaries
```

Or copy `skills/agent-permission-boundaries/` into your agent's skills folder. It can also be pasted into an agent's project rules when skills folders are not supported.
